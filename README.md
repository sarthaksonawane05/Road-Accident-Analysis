# Road Accident Analysis Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze road accident data and identify important patterns, trends, and insights.

## Tools & Technologies
- Microsoft Power BI
- CSV Dataset

## Dashboard Highlights
- Total Accidents
- Total Casualties
- Total Fatalities
- Serious Accidents
- Fatal Accidents
- Accidents by Vehicle Type
- Monthly Accident Trend
- Accidents by Road Type
- Accidents by Weather Condition
- Casualties by Light Condition
- Accident Hotspots by City

## Interactive Features
- City Filter
- Vehicle Type Filter
- Weather Condition Filter
- Accident Severity Filter
- Accident Date Filter
